# Harbourline Joinery - website

Two static pages for a fictional joinery workshop. Used as the "scale down"
test fixture for the `/app-audit` skill.

## Files

| file | what it is |
|---|---|
| `index.html` | home page |
| `about.html` | about page |
| `style.css` | all styling |
| `script.js` | nav highlight + footer year, nothing else |
| `README.md` | this file |

## Deployment

Copy the four files to any static host. There is no build step, no package
manager, no server code.

## Deliberately absent

No forms, no contact form, no newsletter signup, no analytics, no tag manager,
no cookies, no local storage, no third-party scripts or fonts, no user
accounts, no payments, no mobile app. Nothing about a visitor is collected,
stored, or sent anywhere.
